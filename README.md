One sentence, up to 200 characters, about the best advice I ever received.

`main.py` (Python stdlib only) writes exactly one sentence of plain text to `/output/entry.txt` — just the sentence itself, no trailing newline.

Entry: "My dad told me to answer every call like it could be the last one, because one day it was, and his name never lit up my screen again."

Run: `python3 main.py`
